# Пикер Dota 2

Русскоязычный помощник для оценки драфта и подбора героев по позициям.

## Данные

- Список героев и общий винрейт загружаются из OpenDota.
- Данные матчапов загружаются из API OpenDota.
- Портреты героев находятся в `assets/heroes/`.
- Для работы обновляемой статистики нужен доступ к интернету.

Проект не связан с Valve или Dotabuff. Расчёт шанса победы является ориентиром.
